## 4. 资源、验收与结果含义

一个 `0-3` 数组，4个子任务互不依赖，不设 `%2` 等额外并发限制。每个任务64 MPI、1节点、128GB、4h时限，分区64c512g，VASP6.3.2模块。

需要验证电子EDIFF、正常结束、实际ISPIN/NBANDS/NELECT/偶极参数和最终坐标；输出自由原子最大力，不把固定层受力混入验收。

**P0是固定旧几何的诊断单点。** 若SCF已收敛但自由原子力超过0.02 eV/Å，记录 `needs_consistent_relaxation=true`，表示后续需要一致参数短程弛豫，不将其冒充新极小值，也不把这个正常的诊断结果叫做VASP崩溃。程序不自动续算、重提或接上新反应路径。

四点完成后比较：

`DD = [E(M1_OH_H2O)-E(M1_OH)] - [E(M0_OH_H2O)-E(M0_OH)]`。

原E0口径DD=-0.21739583 eV，原TOTEN口径DD=-0.21814632 eV。H2O参考相消，所以无需从已失败的新CaFresh水参考中借用能量，也不需要本轮补新的气相计算。DD不是绝对水吸附能，更不是水解离势垒或腐蚀速率。

## 5. 校准后的继续顺序

1. 核查四点能量、受力、真空电荷/电势；对受力不合格的构型再决定短程弛豫。
2. 在这套校准后的旧结构系列中，重新准备M0/M1 `OH+H2O→2OH+H` 两个原子守恒端点；没有自动恢复已取消的新系列对应Job ID。
3. 基于可信单OH母体设计2OH/4OH排列；缺少洁净表面及气相参考时先用同组成比较或参考相消双差，不混用另一套新晶胞/自旋下的总能量。
4. 只有端点可靠并出现机制判别需要时，再选较高覆盖的水反应或一对关键势垒。
