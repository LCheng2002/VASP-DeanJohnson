## 科学问题与对照

已有结果：在共同S+2H母结构上，H3_addLa的Static TOTEN为-146.97883350 eV，比H3_addMg低0.25772308 eV。该结果只证明两个已采样H3终态的相对稳定性，不证明时间先后顺序。

下一问题：以较低能的H3_addLa为共同母体，加入第4个H后，La关联近表层混合配位位点是否仍优于Mg富集位点？三个试算模型均为Mg68La8H4（80原子），前79个原子的初始坐标完全相同，只改变第4个H的初始位置。

| 模型 | 新增H初始位点的生成方法 | 用途 |
|---|---|---|
| H4_La_partner | 根据H79相对La75的最短周期位移，在La75另一侧构建对应的Mg-La混合配位候选，反转笛卡尔x分量 | 检查La关联区域继续容纳H；不声称已弛豫结构具有严格镜面对称 |
| H4_Mg_top | 当前H3母体的Mg61上方1.80 Å | 延续之前Mg富集顶位对照 |
| H4_Mg_bridge | Mg54与Mg56最短周期连线的中点沿+z抬高1.20 Å | 增加一个Mg多配位对照，避免只拿可能较不利的Mg顶位与La混合配位比较 |

原子编号均为H3母体1-based索引，新增H为第80号原子。名称指初始位置，最终位点要重新按CONTCAR判断。

候选初筛约束：与已有H的最短周期距离至少2.0 Å；最近Mg-H为1.60–2.45 Å；La候选最近La-H为2.0–2.8 Å；Mg候选最近La-H至少3.10 Å；桥位需至少两个Mg在2.55 Å内。这些是建模避碰/分类阈值，不是材料普适的成键或稳定性标准。任何候选不通过，程序整体停止，不绕过检查，也不从错误初始构型强行提交。

## 结果判读

定义Delta4=min(E_H4_Mg_top,E_H4_Mg_bridge)-E_H4_La_partner，采用同一Static能量口径，并同时输出TOTEN与energy(sigma→0)。

- Delta4>0：此次采样中La关联H4终态更稳定。
- Delta4<0：此次采样中Mg富集H4终态更稳定，才支持讨论局部偏好可能发生转移。
- 终态收敛到同一构型或差值很小：不能按初始模型名称强行区分；需进一步检验。

比较同为4H的端点不需要H2化学势。若要绝对第4个H增量吸附能，则应使用E(H4)-E(H3)-0.5E(H2)，且H2参考须先验证与本批参数一致。不直接比较H3与H4裸总能量大小来宣称吸氢更有利。

这是同一H3母体上的最小局部构型筛选，不是所有H4组合的全局基态搜索。不会单凭这些能量证明动力学的“先La后Mg”，也不把N_H=4擅自换算为单层覆盖度或LaH3化学计量。
