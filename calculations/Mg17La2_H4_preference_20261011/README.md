## 科学问题与对照

已有结果：在共同S+2H母结构上，H3_addLa的Static TOTEN为-146.97883350 eV，比H3_addMg低0.25772308 eV。该结果只证明两个已采样H3终态的相对稳定性，不证明时间先后顺序。

本轮问题：以较低能的H3_addLa为共同母体，加入第4个H后，La关联近表层混合配位位点是否仍优于Mg富集位点？三个试算模型均为Mg68La8H4（80原子），前79个原子的初始坐标完全相同，只改变第4个H的初始位置。

| 模型 | 新增H初始位点的生成方法 | 用途 |
|---|---|---|
| H4_La_partner | 根据H79相对La75的最短周期位移，在La75另一侧构建对应的Mg-La混合配位候选，反转笛卡尔x分量 | 检查La关联区域继续容纳H；不声称已弛豫结构具有严格镜面对称 |
| H4_Mg_top | 当前H3母体的Mg61上方1.80 Å | 延续之前Mg富集顶位对照 |
| H4_Mg_bridge | Mg54与Mg56最短周期连线中点沿+z抬高1.20 Å | 增加Mg多配位对照，避免只拿可能较不利的Mg顶位比较 |

编号为母体的1-based原子索引，新增H为第80号原子。名称指初始位置，最终位点必须重新按CONTCAR判断。

## 能量与结论的边界

主对照延续H3的La关联环境与Mg顶位；新增Mg桥位为补充对照。组内可计算Delta4=min(E_H4_Mg_top,E_H4_Mg_bridge)-E_H4_La_partner；正值表示本次采样La候选较稳定，负值表示某Mg候选较稳定。采用相同Static能量口径，同时报告TOTEN和energy(sigma→0)。

比较同为4H的终态不需要H2化学势；绝对第4个H增量吸附能应为E(H4)-E(H3)-0.5E(H2)，H2参考需先核验，不用H3/H4裸总能量大小宣称吸氢有利。

**H3未计算对应的Mg桥位。因此若仅H4_Mg_bridge胜出，不能直接与旧H3的Mg顶位对照混用，宣布覆盖度导致偏好切换。** 应补充匹配的H3桥位或更多构型后再作严格覆盖度因果判断；本轮不为此自动追加任务。详见`INTERPRETATION.md`。

如果不同初始位置弛豫到同一终态，应去重；不能按初始名称强行分组。当前是共同H3母体上的局部构型筛选，不是所有4H组合的全局基态搜索，也没有NEB、H扩散或时间路径。N_H=4不等于La位点已经饱和，更不能直接定义为LaH3化学计量。
