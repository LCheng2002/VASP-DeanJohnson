# Ca 抗腐蚀：重新建模的水/OH覆盖筛选

## 当前文件的意义

本批所有晶格和分子坐标由程序新生成，没有读取或复用既有 POSCAR、CONTCAR、H₂O/OH 吸附结构及旧总能量。23组初始输入是**几何预览**，不是已弛豫结果。正式生产中，后继结构在本批相应母体收敛后重新生成。

初始 Mg 采用理想 hcp：a=3.21 Å、c=5.21 Å，仅为初猜。生产先新算 Mg 体相（晶胞及原子优化），检查晶系、残余应力后，用新 a、c 生成 Mg(0001)。

## 23 个模型的构成

| 组别 | 数量 | 模型 |
|---|---:|---|
| 全新体相/分子参照 | 3 | Mg_bulk、H2、H2O |
| 全新洁净表面 | 2 | M0_clean:Mg96；M1_clean:Mg95Ca1 |
| 单 H₂O、OH、OH+H、OH+H₂O 基线 | 8 | 每种表面各4个 |
| 第二分子水解离终态 | 2 | M0_2OH_H、M1_2OH_H |
| 2OH、4OH 相邻/分散覆盖 | 8 | 两种表面×两种覆盖×两种排列 |
| 合计 | **23** | 原来10个新增目标＋13个重新建立的母体/参照 |

固定的首轮构型筛选，不声称每种覆盖度已找到全局最低能量。

## 表面几何与化学意义

4×4、6层、96个金属位点，固定底部2层（32个原子），真空间隔20 Å；M1仅将一个指定最上层Mg替换为Ca。两表面初始金属位置、吸附位置及原子标签一一对应，除元素替换外相同。Ca占最上层金属位点1/16，不能等同于实验质量百分比。

单水置于指定金属顶位，初始O-H=0.97 Å、H-O-H=104.5°；单OH以相应Mg-Mg或Ca-Mg桥位为初始位置。后续均自由优化可移动原子，不保持人工H-O约束。

单水解离和第二分子水解离均通过移动已有的一个H构造端点，不增加或删除原子。若分子初态在优化中已经解离，或OH母体不再保持羟基，后续会停止并要求重新解释真实构型，不把名称当作计算结果。

2OH和4OH分别对应2/16、4/16的名义覆盖。相邻排列与分散排列有相同化学组成，可比较局部聚集倾向；这些仍不是连续Mg(OH)₂保护膜。

## 数值口径

PBE、ENCUT=520 eV、ISPIN=2、无U、ISMEAR=0/SIGMA=0.05、LREAL=.FALSE.、EDIFF=1e-7。表面固定晶胞；Relax最大自由原子力<0.015 eV/Å，Static重新验收<0.020 eV/Å。新分子/体相参考用更严的0.005 eV/Å（分子电子1e-8）；Mg体相额外检查应力。

表面K点Γ3×3×1，Mg体相15×15×11，气相分子Γ单点和20 Å盒子。表面开启LDIPOL/IDIPOL=3，分子IDIPOL=4。所有新能量单独成组，不能和原表中的旧能量混用。

本轮仍是中性真空薄片的端点热力学模型，不含显式水层、电极电势、NEB、AIMD、DOS/Bader、氯离子或完整膜。后续须对关键趋势考虑尺寸、展宽、溶剂/氢键和色散敏感性。

## 执行顺序

每个新任务仅依赖其直接需要的本批母体。例如，Mg_bulk→M0_clean→M0_OH→M0_2OH/4OH；水解离仅依赖自己的分子初态。H₂O/H₂参考失败不阻断无关几何优化，但在参考修复前不能报告吸附或形成能。没有复用旧失败数组的依赖关系。

生产固定目录：`~/Ca_corrosion_fresh_20261014/`。每个表面模型64 MPI、128 GB、24小时上限；气相4 MPI、16 GB、1小时；Mg体相16 MPI、32 GB、2小时。只允许固定23个作业各提交一次；提交回执不明或目录冲突时停止，不自动重试，不覆盖旧项目。

首次提交尝试已成功连接思源一号，但默认赝势目录未找到Ca、H、O，故在sbatch前主动停止。后续用`prepare_potentials.py`仅在集群本地定位已有授权POTCAR，未读取旧结构或旧能量。最终结果请以STATUS.md和真实submission.json为准，不把GitHub输入验证当作计算完成。

## 结果将回答什么

1. 新口径下Ca是否仍增强水、OH及OH+H终态的稳定性？
2. 单OH覆盖后再来一分子水，其分子态与2OH+H终态能差是否改变？
3. 增加到2OH和4OH时，增量羟基化及相邻/分散排列的优势是否延续？

这些结果用于筛选羟基化和后续反应的机制，不能直接称为抗腐蚀已经被证明。
